The phone connects to this computer over Wi-Fi with Android's Wireless debugging. Both must be on the same network.

  1. On the phone: Settings → About phone, tap Build number 7 times (turns on Developer options).
  2. Settings → System → Developer options → Wireless debugging: turn it on.
  3. Tap Pair device with QR code and scan the code below.

Screen · DND–

Screen off turns only the display panel off; the camera keeps running and touches still reach the app. A back gesture on the phone (swipe in from a screen edge) turns it on again. The screen button is in the left bar.

Capabilities

Learning…

Hardware facts come from Android; formats and frame rates from Blackmagic Camera, learned for each lens while it's active. Scan lenses in the left bar switches through all lenses (a few seconds each) and then restores your settings.

Recordings

Loading…

Live view mirrors the phone's screen (overlays included) and sound comes from the phone's microphone; both run over adb, so keep Wireless debugging on. Setting ISO or shutter switches exposure to Manual; moving the focus slider switches autofocus off; moving white balance locks it (use the phone to return WB to auto). Space bar = record.
